# Awesome Peptide Testing Labs [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> This repository is research done by **[Volta Peptides](https://voltapeptides.com/)**. The maintained directory, with a full page per laboratory, can be found at **[voltapeptides.com/testing-labs](https://voltapeptides.com/testing-labs)**. The compounds these laboratories test are in the [Volta Peptides catalogue](https://voltapeptides.com/catalog).

A curated list of independent laboratories that analyse research peptides, grouped by country: what each one measures, what it charges as published, how long it takes, and whether you can check one of its reports on its own website.

Every figure is copied from the laboratory's own site in the currency it publishes, and never converted. Where a laboratory quotes per job rather than publishing a price, the entry says so instead of leaving a blank. Each entry carries the date it was read, and time-limited notices (paused intake, a relocation) are dated so you can tell when they may have lapsed. Confirm with the laboratory before you ship a vial.

The same data is in [`data/labs.json`](data/labs.json) and [`data/labs.csv`](data/labs.csv).

## How to read this list

- **Measures** uses one fixed vocabulary across every laboratory, assigned from a service the laboratory publishes. Laboratories describe the same test in different words; this field does not.
- **ISO/IEC 17025** is marked only for accreditation held from a named body with a published scope. "Aligned with" and "accreditation pending" do not count. An accreditation can cover one method and not another, so check the scope.
- **Does not take peptide samples** marks entries that were once listed as peptide laboratories and are not. They stay, with the correction, because the wrong version was public long enough to be read.
- There is no ranking and no recommended section. Which laboratory suits you depends on the compound, the question and where you are posting from.

## Comparing a result against a specification

Most of the laboratories above list the same research peptides. To compare a report against the specification it should meet, start from the product page, which carries the CAS number, formula and molecular weight:

- [BPC-157 5mg](https://voltapeptides.com/product/bpc-157-5mg) and the [BPC-157 compound hub](https://voltapeptides.com/peptides/bpc-157)
- [GHK-Cu 50mg](https://voltapeptides.com/product/ghk-cu-50mg) and the [GHK-Cu compound hub](https://voltapeptides.com/peptides/ghk-cu)
- [TB-500 10mg](https://voltapeptides.com/product/tb-500-10mg)
- [GLP-3 RT 10mg](https://voltapeptides.com/product/glp-3-rt-10mg)
- [Ipamorelin 5mg](https://voltapeptides.com/product/ipamorelin-5mg)

Or browse by composition: [peptides](https://voltapeptides.com/catalog?type=peptides), [peptide blends](https://voltapeptides.com/catalog?type=peptide-blends) (which need a laboratory that resolves each component separately), [copper peptides](https://voltapeptides.com/catalog?type=copper-peptides), [bioregulators](https://voltapeptides.com/catalog?type=bioregulators) and [cofactors and small molecules](https://voltapeptides.com/catalog?type=cofactors-small-molecules). Volta Peptides publishes its own [certificates of analysis](https://voltapeptides.com/coas) with each laboratory's report number and verification link.
